Read `docs/COMMANDS.md`, then run `.venv/bin/python -m kandu.config --refining-way` on the brain: it prints the install's refining way. If it prints `grilling`, follow `prompts/grilling.md`, every step, and `prompts/domain-modeling.md` throughout, then `prompts/to-spec.md` and `prompts/to-ticket.md`, every step, as `/kandu-grill-with-docs` and `/kandu-to-issue` do. If it prints `rounds`, define the task as `prompts/defining.md` says, every step. Finish when the way's last step is done.
