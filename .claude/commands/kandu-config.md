description: Change Kandu's config, by conversation
---
Read `docs/COMMANDS.md`, then make the change the user asks for in `local/kandu.yaml` or `local/projects.yaml`, for example "pause this project" or "set the weekly limit to 50%". To change the default look, ask which: Classic, Classic new or Kandu Clean (`dashboard.look`: `classic`, `classic-new` or `clean`). To let runs read a task's `Reference` into another registered project's repo, ask whether to turn on the read-only copy (`supervisor.reference_copy`, off by default; only the named paths, never from a private repo into a run on a public one; it can also be switched in the dashboard). To change the branch a project's work starts from, its PRs target and Kandu merges into, set its `base_branch` in `local/projects.yaml`, or remove it to go back to the repo's default branch; the branch must exist on GitHub, or the project's tasks wait. Show the exact change and wait for a yes. Keep comments and other entries as they are. Finish when `.venv/bin/python -m kandu.config` passes. Removing a project only removes its entry: its board, repos and clone stay.
